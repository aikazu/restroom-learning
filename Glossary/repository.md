# Repository

> Satu kalimat sederhana: Repository itu **folder proyek yang dicatat [Git](./git.md)**.

## Analogi Sehari-hari

Folder biasa = tas kresek: isinya ada tapi tidak tercatat. Repository = tas dengan buku inventaris: tiap barang keluar-masuk dicatat, jadi bisa dilacak dan dikembalikan.

## Penjelasan Teknikal

Satu repository = satu proyek (misal repo `portfolio`). Berisi kode + riwayat commit. Kalau diupload ke GitHub, namanya remote repository — tempat Cloudflare mengambil kode untuk [Deploy](./deploy.md).

## Kapan Kamu Ketemu Istilah Ini?

"Buat repo baru", "push ke repo", "clone repo" — selalu artinya folder proyek ini.
