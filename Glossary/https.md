# HTTPS

> Satu kalimat sederhana: HTTPS itu **gembok pengaman** — tandanya koneksi ke website terenkripsi.

## Analogi Sehari-hari

HTTP biasa seperti mengirim surat terbuka: siapa pun di jalan bisa baca. HTTPS seperti surat di amplop tersegel + dikirim kurir terpercaya. Isi [Form](./form.md) kontakmu tidak bisa diintip di tengah jalan.

## Penjelasan Teknikal

HTTPS = HTTP + enkripsi (TLS). Browser menampilkan ikon gembok dan `https://`. Cloudflare memberi sertifikat HTTPS **gratis dan otomatis** untuk semua site Pages — kamu tidak perlu beli atau setting.

## Kapan Kamu Ketemu Istilah Ini?

Selalu: browser modern memberi peringatan kalau situs masih `http://` tanpa S.
