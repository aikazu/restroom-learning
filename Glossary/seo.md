# SEO

> Satu kalimat sederhana: SEO itu **cara biar websitemu gampang ditemui Google**.

## Analogi Sehari-hari

Google seperti pustakawan. SEO = memberi label jelas di bukumu: judul di sampul (title), sinopsis di belakang (description), daftar isi rapi (heading), dan nama pengarang. Buku berlabel jelas ditaruh pustakawan di rak depan; buku tanpa label nyangkut di gudang.

## Penjelasan Teknikal

Dasar SEO untuk portfolio (gratis, tanpa tool aneh):

1. Satu `<h1>` jelas per halaman ("Portfolio Iqbal — Web Developer").
2. `title` + `meta description` yang manusiawi.
3. Gambar punya teks alt.
4. Loading cepat ([Static Site](./static-site.md) + [CDN](./cdn.md) sudah membantu).
5. Ada di sitemap bila pakai framework.
