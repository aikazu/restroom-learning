# DNS

> Satu kalimat sederhana: DNS itu **buku teleponnya internet** — menerjemahkan nama menjadi nomor.

## Analogi Sehari-hari

Kamu cari "Budi" di kontak HP, HP yang tahu nomornya. DNS sama: kamu ketik `iqbal.dev`, DNS yang tahu alamat servernya (`104.21.x.x`) dan mengarahkan browser ke sana.

## Penjelasan Teknikal

Saat domain didaftarkan, pemiliknya mengisi "catatan DNS" (record): nama ini → server itu. Cloudflare mengatur ini otomatis saat kamu pakai Pages + domain mereka.

## Kapan Kamu Ketemu Istilah Ini?

Saat menghubungkan [Domain](./domain.md) sendiri ke [Hosting](./hosting.md). Kalau pakai domain gratis `*.pages.dev`, kamu tidak perlu menyentuhnya.
