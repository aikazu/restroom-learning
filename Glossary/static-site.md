# Static Site

> Satu kalimat sederhana: Static Site itu **website yang sudah jadi duluan** — tinggal disajikan, tidak dimasak per pengunjung.

## Analogi Sehari-hari

Warung nasi bungkus vs restoran masak-di-tempat. Static site = nasi bungkus yang sudah dibungkus rapi pagi-pagi; pembeli datang, langsung ambil. Cepat, murah, dan tidak butuh dapur ([Backend](./backend.md)) yang selalu menyala.

## Penjelasan Teknikal

File HTML/CSS/JS-nya sudah final saat [Deploy](./deploy.md). Server ([Hosting](./hosting.md)) tinggal mengirim file yang sama ke semua orang. Portfolio idealnya static site: cepat, gratis, aman. Data dinamis (misal pesan kontak) tetap bisa — diambil/dikirim lewat [API](./api.md) [Supabase](./supabase.md) dari browser.

## Kapan Kamu Ketemu Istilah Ini?

Saat memilih jenis portfolio: selalu pilih static site dulu.
