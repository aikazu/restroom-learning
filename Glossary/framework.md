# Framework

> Satu kalimat sederhana: Framework itu **kerangka rumah setengah jadi** — kamu tinggal isi dindingnya.

## Analogi Sehari-hari

Bangun rumah dari nol (pasir + semen) vs dari kerangka prefab: pondasi, tiang, dan atap sudah ada polanya. Framework = kerangka prefab untuk kode: struktur folder, cara menampilkan halaman, dan aturan main sudah ditentukan — kamu fokus isi kontennya.

## Penjelasan Teknikal

Contoh framework frontend: Next.js, Astro, SvelteKit. Mereka mengubah [Component](./component.md)-component [TypeScript](./typescript.md)-mu menjadi [Static Site](./static-site.md) yang siap [Deploy](./deploy.md) ke [Cloudflare](./cloudflare.md). Untuk portfolio pertama, framework yang ringan (misal Astro) lebih dari cukup.

## Kapan Kamu Ketemu Istilah Ini?

Saat materi bilang "pakai ... untuk bikin portfoliomu" — itu nama framework.
